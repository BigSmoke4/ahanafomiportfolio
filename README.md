## 📜 About

A visually stunning, single-page portfolio website inspired by ancient Greek aesthetics. This showcase features smooth animations, responsive design, and an immersive user experience that highlights my expertise in full-stack development, distributed systems, and AI-powered applications.

### ✨ Features

- 🎨 **Ancient Greek Theme**: Marble textures, classical typography, and golden accents
- 🎬 **Cinematic Animations**: GSAP-powered smooth transitions and scroll effects
- 📱 **Fully Responsive**: Optimized for all device sizes from mobile to desktop
- 🎵 **Ambient Audio**: Background music with user-controlled playback
- 🖼️ **Visual Navigation**: Floating circular navigation with project previews
- ⚡ **Performance**: Optimized loading and smooth rendering
- 🎯 **Interactive Elements**: Clickable project navigation and skill displays

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/BigSmoke4/ahanaf-portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd ahanaf-portfolio
   ```

3. **Open the website**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve
     ```

4. **Access the website**
   - Open `http://localhost:8000` in your browser

## 🎮 Customization

### Changing Colors
Modify the CSS variables in the `<style>` section:
```css
/* Golden accent color */
--gold: #d4af37;

/* Background colors */
--bg-dark: #1a1a1a;
--text-light: #e8e8e8;
```

### Updating Content
- **Projects**: Modify the `projects` array in the JavaScript section
- **Skills**: Update skill icons and data attributes
- **Experience**: Edit HTML content in the experience section
- **Contact**: Update email, LinkedIn, and GitHub links

### Adding New Projects
```javascript
const projects = [
    {
        number: "14",
        title: "YOUR PROJECT",
        subtitle: "Project Description",
        technologies: "Tech1, Tech2, Tech3",
        description: "• Key achievement 1\n• Key achievement 2",
        link: "https://github.com/yourusername/project",
        linkType: "github"
    }
];
```

## 🎵 Audio Control

The website features ambient background music:

- **Default**: Music is muted by default
- **Activation**: Click the speaker icon (top-right) to start music
- **Control**: Click again to mute/unmute
- **File**: Replace `music.mp3` with your preferred audio file
